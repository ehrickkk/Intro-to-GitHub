# Intro-to-GitHub

## Purpose
A starter repository created as part of an assignment to demonstrate the basic concepts and workflows of Git and GitHub, including version control, repository creation, file management, and local synchronization.

## Files Included
* `index.html` - An HTML file displaying a basic introduction message.
* `script.py` - A Python script printing an introductory statement.
* `App.jsx` - A React JSX component rendering an introductory header.

## Requirements Covered
- Git & GitHub fundamentals
- Repository setup & file management
- Local cloning, committing, and pushing changes
